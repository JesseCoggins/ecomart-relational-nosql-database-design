# Retail data sources

| File | Project use |
|---|---|
| `Sales_Records.csv` | 100,000 sales records loaded through the PostgreSQL staging table |
| `groceries.json` | Grocery member purchase-frequency queries in MongoDB |
| `cosmetics.json` | Product suitability, ranking and ingredient queries in MongoDB |

These inputs were provided for the WGU database-design coursework. The sales columns match the mapping in [the load script](../sql/03_load_from_staging.sql). EcoMart is the retail reporting scenario.
